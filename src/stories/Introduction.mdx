# ADVI-UI

A personal React component library built with **React**, **TypeScript**, **Tailwind CSS**, **SCSS**, and **Storybook**.

## Install

```bash
npm install advi-ui
```

```ts
import { Button, ThemeProvider, ToastProvider, Header } from 'advi-ui';
import 'advi-ui/base';  // component styles + Tailwind base, no colors
import 'advi-ui/fonts'; // optional — self-hosted Raleway, Unbounded, Rubik
```

```tsx
<ThemeProvider theme="default" mode="system">
  <Button variant="outline">Hello</Button>
</ThemeProvider>
```

`advi-ui/base` carries no colors — `ThemeProvider` supplies them, with
runtime switching via `useTheme().setTheme`/`setMode` and support for
registering your own themes. See Theming below, or skip `ThemeProvider`
and use a plain CSS theme import instead (`advi-ui/styles` still works as
a single import equal to `base` + `theme/default`, for anyone who doesn't
need `ThemeProvider`).

## Components

**UI primitives** — Button, Card, Input, Textarea, Link, Dialog, Modal, ToastProvider, Loading

**Layout & interaction** — Header, ScrollAnimationBtn, PageNotFound, PageAside

## Theming

Every component reads color only through a fixed set of semantic CSS
variables (`--popover`, `--muted-foreground`, etc.) — never a hardcoded
value. Modes are fixed (`light`/`dark`/`system`); a theme just supplies a
palette for either or both:

| Theme | Description |
|---|---|
| `"default"` | Stock shadcn zinc/slate palette. `light` + `dark`. |
| `"midnight"` | Dark teal surfaces, burnt-orange accent. `dark` only — `light` falls back to `"default"`'s. |

Register your own via `ThemeProvider`'s `themes` prop, or skip it and
define the same variables yourself in a `:root` block (CSS-only path) —
see [THEMING.md](https://github.com/1atharvad/advi-ui/blob/main/THEMING.md)
in the repo for the full `ThemeProvider` API, the variable contract, and
value format (HSL triplet, no `hsl()` wrapper).

## Icons

Components default to [lucide-react](https://lucide.dev) icons. Any
component with a built-in icon (`Header`, `PageAside`, `SearchInput`,
`Select`, `MultiSelect`, `Modal`, `Dialog`) accepts icon-override props to
swap in any icon library per-instance — Phosphor, Radix Icons, Heroicons,
your own SVGs:

```tsx
import { MagnifyingGlass, X } from '@phosphor-icons/react';

<SearchInput searchIcon={<MagnifyingGlass />} clearIcon={<X />} />
```
